Questions about the component

Do I need ACF Pro?

No. The fields run on Advanced Custom Fields (free) and on Secure Custom Fields. Both are detected, neither is required for the output.

What happens to existing pages on an update?

The data stays where it is. If a version renames a stored key, a migration moves the content along — automatically, and additionally through a WP-CLI command with a dry run.

Can I create my own components?

Yes: a directory with definition.json, render.php and component.css. The component then appears in the component list and in the inserter.

Does it work without JavaScript in the frontend?

Yes. The output is HTML and CSS; accordions are details elements, ratings a meter element. Only the editor needs JavaScript.
