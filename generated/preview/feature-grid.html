Built for editorial teams

No shortcodes, no HTML in an editor field. Every component is a block with fields you can fill in without a manual.

  • The editor knows the structure. Nested lists, repetitions and images are maintained as fields, not as HTML.

  • Frontend and editor preview call the same PHP file. What stands in the editor is what gets delivered.

  • Every value is escaped. A missing view is reported instead of silently rendering an empty area.

  • Definition lists for facts, details and summary for seasons, meter for ratings — operable by keyboard, without JavaScript.
